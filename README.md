# 아캄의 한 생애

1900년에 태어나 아캄에서 살아가는 한국어 인생·조사 게임입니다.

[브라우저에서 플레이](https://mistbound-archives.github.io/arkham-life/)

HTML·CSS·JavaScript로 실행되며 별도 설치나 계정이 필요하지 않습니다. 진행 기록은 현재 브라우저에 저장됩니다. 다른 기기나 브라우저로 자동 이전되지 않습니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다.

러브크래프트의 세계에서 영감을 받은 비공식 독립 창작 게임입니다.
